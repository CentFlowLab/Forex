# Avisos de terceiros

## TradingAgents (Tauric Research)

Este projeto adapta conceitos e a arquitetura multiagente do framework
[TradingAgents](https://github.com/TauricResearch/TradingAgents)
(commit `1394a3f72aa4393e1a98f51b382434c4b4c2d972`).

Copyright dos autores originais do TradingAgents.
Licença: Apache License 2.0 — ver `vendor/TradingAgents/LICENSE`.

A adaptação para Forex intraday EUR/USD, a integração com o motor de risco
determinístico e o painel GROK FOREX AI são código próprio deste repositório.
Não se inclui o pacote `tradingagents` como dependência de runtime.
